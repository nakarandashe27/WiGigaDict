# Vendor-neutral runbook для AI-агента

Этот документ предназначен для Claude, Codex, Grok и любого другого coding/computer-use агента на Windows. Цель — установить WiGigaDict безопасно и воспроизводимо, не расширяя полномочия агента.

## Готовый prompt

Скопируйте агенту следующий текст:

> Установи WiGigaDict из официального репозитория `https://github.com/nakarandashe27/WiGigaDict`. Следуй `docs/AGENT_INSTALL.md`. Используй последний опубликованный релиз, включая prerelease, если стабильного релиза ещё нет. Скачай NSIS x64 installer и `SHA256SUMS.txt` из одного релиза, проверь SHA-256 и только после совпадения запусти установщик для текущего пользователя. Не отключай SmartScreen, антивирус или политики Windows, не запрашивай права администратора и не удаляй пользовательские данные. Перед загрузкой модели сообщи варианты и размер и дождись моего выбора. В конце покажи версию, путь installer, проверенный SHA-256 и результат запуска приложения.

## Контракт выполнения

Агент должен:

1. Работать только с репозиторием `nakarandashe27/WiGigaDict` и его GitHub Releases.
2. Сначала проверить Windows x64 и доступное место: минимум 200 МБ для приложения плюс размер выбранной модели.
3. Выбрать последний release, который не является draft. Prerelease допустим, пока проект имеет статус alpha.
4. Скачать ровно один файл `WiGigaDict_*_x64-setup.exe` и `SHA256SUMS.txt` из одного release.
5. Сравнить фактический SHA-256 installer с записью в checksum-файле. При отсутствии строки, неоднозначном asset или несовпадении немедленно остановиться.
6. Запустить installer без elevation. Тихий флаг NSIS `/S` допустим только если пользователь запросил unattended-установку.
7. Запустить WiGigaDict и убедиться, что главное окно открывается. Не считать скачивание модели частью установки без отдельного согласия пользователя на её размер и лицензию.
8. Сообщить проверяемый итог: tag релиза, URL страницы релиза, локальный путь, SHA-256 и результат запуска.

Агенту запрещено:

- использовать сторонние зеркала, repack или «download»-сайты;
- выполнять `irm ... | iex`, `curl ... | sh` и другие непросматриваемые pipe-to-shell команды;
- обходить SmartScreen, Defender или корпоративные политики;
- продолжать после несовпадения checksum;
- считать одиночный `wigigadict-desktop.exe` portable-сборкой;
- удалять `%LOCALAPPDATA%\WiGigaDict` или пользовательский архив при обновлении/удалении;
- загружать модель, не показав пользователю размер и требования.

## Рекомендуемый автоматизированный путь

Если репозиторий уже клонирован и пользователь разрешил установку:

```powershell
pwsh -NoProfile -File .\scripts\install-release.ps1 -Silent
```

Для визуальной установки уберите `-Silent`. Скрипт сам выбирает release, загружает оба файла и завершает работу до запуска installer при любой ошибке проверки.

## Ручной алгоритм без helper-скрипта

1. Получить JSON `https://api.github.com/repos/nakarandashe27/WiGigaDict/releases?per_page=20`.
2. Взять первый объект с `draft == false` либо release с запрошенным tag.
3. Найти единственные assets с именами по шаблонам `WiGigaDict_*_x64-setup.exe` и `SHA256SUMS.txt`.
4. Скачать их через HTTPS в отдельный локальный каталог.
5. Выполнить `Get-FileHash -Algorithm SHA256` и сопоставить хэш со строкой checksum-файла для точного имени installer.
6. При совпадении запустить installer. При несовпадении удалить только скачанный подозрительный файл и сообщить об ошибке.
7. Проверить запуск приложения из меню «Пуск» или стандартного per-user пути.

## Критерий готовности

Установка завершена, когда checksum совпал, installer завершился с кодом `0`, WiGigaDict запускается, а пользователь получил предупреждение, что для первой диктовки нужно отдельно выбрать и скачать модель. Настройка микрофона, горячей клавиши и локального архива выполняется после запуска.
