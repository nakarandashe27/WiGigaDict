# Способность: транскрибировать запись

Статус: 🔜 **M2 после personal alpha**. До M1 разрешены только architecture/research spikes.

## Когда применять

- Preflight принял локальный либо durable-скачанный media source и зарезервировал место под managed PCM.
- Пользователь возобновляет paused/needs-source job с тем же подтверждённым содержимым.

## Когда НЕ применять

- Через FSM `DictationSession`, insertion pipeline или отдельный cloud ASR.
- До прохождения 30/60-секундного ASR gate и многочасового soak без drift, truncation и seam duplicates.

## Примеры

- **Good:** `NotetakerJob` декодирует выбранную аудиодорожку в durable PCM S16LE 16 kHz mono, атомарно commit-ит raw-сегменты каждого чанка и после restart продолжает с последнего checkpoint.
- **Bad:** превратить `DictationSession` в nullable `Record`, добавить поля source URL и export path и прогнать многочасовой файл через короткую FSM диктовки.

## Что может пойти не так

FFmpeg возвращает corrupt/no-audio/unsupported input, sidecar падает/OOM, источник меняется, диск заканчивается или chunk stitching теряет/дублирует речь. Использовать отдельные status/stage/reason, один автоматический transient retry, durable chunk checkpoints, immutable raw timings и отдельную stitched version. Dictation имеет абсолютный runtime priority: Notetaker приостанавливается на границе чанка и автоматически продолжается после диктовки.
