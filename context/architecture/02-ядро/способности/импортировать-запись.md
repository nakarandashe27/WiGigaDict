# Способность: импортировать запись

Статус: 🔜 **M2 после personal alpha**. Production-реализация запрещена до прохождения M1 gates.

## Когда применять

- Пользователь явно выбирает один локальный аудио- или видеофайл для Notetaker.
- Пользователь отдельно включил network-import capability и явно запускает скачивание одного публичного файла по ссылке Яндекс.Диска.

## Когда НЕ применять

- Для Dictation, захвата встречи с микрофона, фонового обхода папок или автоматического fetch.
- Для OAuth, приватных ресурсов, папок, паролей, ссылок с запретом скачивания или обхода ограничений Яндекс.Диска.

## Примеры

- **Good:** локальный файл проходит probe по содержимому, фиксируются path/size/mtime/hash, после чего он читается без копирования и изменения.
- **Good:** после кнопки «Скачать и распознать» официальный API возвращает временный download URL, файл durable-скачивается в managed `.part → final`, а UI явно показывает сетевую стадию.
- **Bad:** WebView сам обращается по вставленной ссылке, следует произвольным redirect или незаметно начинает загрузку при вставке URL.

## Что может пойти не так

Локальный источник исчезает или меняется, ссылка истекает, сервер не поддерживает resume, DNS/redirect ведёт в private/link-local сеть, файл превышает лимит либо диск не вмещает staging и PCM. Local path переходит в `needs_source`; сетевой ingress использует только HTTPS, официальный API, строгую нормализацию, проверку каждого redirect/address, двойной лимит по `Content-Length` и фактическим байтам и bounded retry. До приёма резервируется требуемое место плюс 20%.

## UX, согласие и privacy copy

При первом открытии Notetaker показывается одно локальное подтверждение:

> Записывайте и обрабатывайте материалы только при наличии законного права и необходимых согласий участников. Вы несёте ответственность за соблюдение применимых правил.

Кнопка: «Понимаю, продолжить». Сохраняются `notice_version` и `accepted_at`; повтор нужен только при существенном изменении текста.

Постоянное напоминание на import screen:

> Убедитесь, что у вас есть право обрабатывать эту запись. Локальные файлы распознаются без сети. Файл по ссылке Яндекс.Диска сначала скачивается по вашей команде, затем распознаётся локально.

Первое включение Yandex capability отдельно объясняет, что приложение передаст введённую public URL Яндексу и скачает файл. Capability не запускает сеть; каждое фактическое скачивание требует «Скачать и распознать».

Продуктовое обещание формулируется послойно: распознавание, таймкоды и транскрипты обрабатываются и хранятся на компьютере; local import полностью offline; Yandex import имеет явную network download stage, но не отправляет запись в сторонний ASR service.
