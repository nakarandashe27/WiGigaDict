# Способность: экспортировать транскрипт

Статус: 🔜 **Notetaker v1 / M2**.

## Когда применять

- Пользователь просматривает `completed` или явно неполный `incomplete` transcript и выбирает TXT, SRT либо VTT и конечный путь.

## Когда НЕ применять

- Для автоматической вставки в active target, DOCX, Markdown-протокола, summary или скрытой публикации наружу.
- Для перезаписи raw/stitched transcript version либо изменения исходного media.

## Примеры

- **Good:** приложение детерминированно создаёт UTF-8 TXT с `[HH:MM:SS – HH:MM:SS] текст`, пишет временный файл в выбранной папке и атомарно заменяет final только после подтверждения collision.
- **Bad:** автоматически сохранить экспорт рядом с исходником, перезаписать существующий файл или считать экспорт managed-копией, которую удалит retention sweep.

## Что может пойти не так

Имя содержит недопустимые Windows-символы, файл уже существует, выбранный volume переполнен или rename невозможен. Санитизировать только предлагаемое имя, использовать fallback `Транскрипт YYYY-MM-DD HH-mm`, не изменять выбранную папку, безопасно подтверждать overwrite и не объявлять export готовым до durable commit.
