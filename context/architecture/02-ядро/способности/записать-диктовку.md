# Способность: записать диктовку

## Когда применять

- Пользователь впервые нажал настроенный global toggle hotkey в состоянии `Idle`.

## Когда НЕ применять

- Для фонового always-listening, активации по шуму или запуска без физического действия пользователя.
- Когда уже существует active recording session или микрофон не прошёл health check.

## Примеры

- **Good:** первый физический key-down создаёт `DictationSession`, фиксирует target snapshot, открывает микрофон и сразу показывает Recording; второй отдельный key-down завершает эту же session.
- **Bad:** WiGigaDict начал запись при старте Windows, чтобы «быть готовым» — нет пользовательского согласия на capture.

## Что может пойти не так

Hotkey конфликтует, физический key-up теряется, устройство отключается или Windows генерирует auto-repeat. Использовать physical-state debounce, single active session, recording watchdog и явную отмену; доступный audio fragment фиксировать до перехода в recoverable failure. Подробности: [триггеры](../../04-потоки/триггеры.md).
