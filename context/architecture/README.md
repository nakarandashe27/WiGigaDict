# Архитектура WiGigaDict

Контракт между будущим мной и AI для проекта WiGigaDict — какой система должна стать и почему; начат 20 августа 2026 года.

## 🚀 Текущий план разработки

[08-дорожная-карта/roadmap.md](08-дорожная-карта/roadmap.md) — пошаговый план с чекбоксами `[ ]` / `[x]`. Точка входа для разработки.

## Статус

Архитектура собрана по working-backwards процессу. Stages 1–13 завершены; Stage 5 осознанно пропущен, поскольку в продукте нет автономного AI-агента или долговременной LLM-памяти. ✅ M0 и M1 Steps 5–14 реализованы; Step 15 diagnostics/security hardening — первый открытый production step. Подтверждённый Notetaker v1 остаётся отдельным 🔜 M2 после personal alpha, а его feasibility reports не считаются production implementation.
