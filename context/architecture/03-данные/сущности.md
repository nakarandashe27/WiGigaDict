# Сущности WiGigaDict

## Принцип модели

Глобального универсального `Record` нет. `DictationSession` — aggregate root Dictation; M2 `NotetakerJob` — отдельный aggregate готовых записей. Их operational children не смешиваются. Модели, runtime, storage primitives и diagnostics переиспользуются через строгие контракты согласно [принятому решению](главный-кирпич.md#принятое-решение).

Имена полей ниже логические: физические типы и конкретное хранилище будут выбраны на Stage 9.

## Основной aggregate диктовки

| Сущность | Назначение | Основные поля и причина | Связи |
|---|---|---|---|
| `DictationSession` | Единственный корень lifecycle диктовки и recovery | `id` — стабильная identity; `pipeline_state` — допустимый FSM state; `state_version` — compare-and-set/dedup; `outcome` — delivered/uncertain/failed/cancelled/resolved отдельно от стадии; `started_at` — начало capture; `finalized_at?` — момент, после которого действует zero-loss gate; `delivered_at?` — основание 15-дневного cutoff; `resolved_at?` — явное разрешение; `pinned_at?` — запрет retention delete; `retention_expires_at?` — вычисленный cutoff для delivered; `last_error_code?` — основной диагностируемый исход; `created_at`, `updated_at` — аудит изменения aggregate | 1:N со всеми session children; не владеет конфигурацией/моделью |
| `TargetSnapshot` | Неизменяемый снимок назначения для первоначальной или повторной вставки | `id`; `session_id` — FK; `purpose` — initial/retry; `process_identity` — сравнение приложения без чтения контента; `process_id`, `thread_id` и `window_handle` — проверка живого target; `window_class` и `control_class` — точное сопоставление compatible path; `process_version` и `os_build` — versioned evidence boundary; `integrity_level` и `integrity_rid` — запрет elevated insertion; `captured_at` — порядок снимков | N:1 к session; 1:N к delivery operations |
| `AudioArtifact` | Recoverable вход ASR и сторона файлового commit-протокола | `id`; `session_id` — FK; `commit_id` — idempotency/reconciliation key; `staging_storage_key` и `storage_key?` — `.part` и неизменяемый final path внутри одного managed volume; `format`; `duration_ms?`; `reserved_byte_size` — admission budget; `byte_size?` и `content_hash?` — проверяемые фактические значения; `artifact_state` — writing/finalized/corrupt/deleted; `last_verified_at?`; `created_at`; `retention_expires_at?` | N:1 к session; 1:N к ASR attempts; `commit_id` уникален, final path появляется до DB-маркера `finalized` |
| `SessionEvent` | Append-only журнал допустимых переходов и источник crash recovery | `id`; `session_id` — FK; `sequence_no` — строгий порядок; `event_type`; `from_state?`, `to_state?` — проверка FSM; `source` — user/system/windows; `reason_code?` — объяснение; `metadata` — только allowlisted технические поля, включая `commit_id` для storage-переходов; `occurred_at` | N:1 к session; уникален по `(session_id, sequence_no)` |

## Распознавание и очистка

| Сущность | Назначение | Основные поля и причина | Связи |
|---|---|---|---|
| `AsrAttempt` | Одна воспроизводимая durable-задача локального распознавания | `id`; `session_id`, `audio_artifact_id`, `runtime_profile_id` — FK; `attempt_no` — retry order; `idempotency_key` — single-flight; `language_hint?`; `status` — queued/leased/running/succeeded/failed/cancelled; `queued_at`; `lease_owner?`, `lease_expires_at?`, `heartbeat_at?`, `lease_generation` — generation-bound возврат той же задачи после crash worker; `started_at?`, `completed_at?`; `error_code?`; `metrics` — allowlisted RTF/device timings | N:1 к session/audio/runtime; 1:0..1 raw transcript; SQLite-поля являются очередью истины, не in-memory channel |
| `TranscriptVersion` | Immutable raw или cleaned версия текста | `id`; `session_id` — FK; `kind` — raw/cleaned; `version_no` — порядок внутри kind; `content` — пользовательский результат; `content_hash` — integrity/dedup; `source_asr_attempt_id?` — FK для raw; `source_cleanup_attempt_id?` — FK для cleaned; `created_at` | N:1 к session; source FK строго соответствует kind; 1:N delivery operations |
| `CleanupAttempt` | Воспроизводимая трансформация одной text version | `id`; `session_id`, `input_transcript_id` — FK; `cleanup_profile_id?` — built-in default допускает null; `policy_version`, `policy_hash` и `glossary_revision` — точный набор правил; `status`; `started_at`, `completed_at?`; `error_code?`; `metrics` — latency/rule counts/disagreement без содержимого | N:1 к session/input/profile; 1:0..1 cleaned transcript; built-in identity уникальна по `input + policy_version + policy_hash + glossary_revision` |

## Доставка и recovery

| Сущность | Назначение | Основные поля и причина | Связи |
|---|---|---|---|
| `DeliveryOperation` | Группа попыток доставки для первоначального insert или явного Retry | `id`; `session_id`, `transcript_version_id`, `target_snapshot_id` — FK; `operation_no`; `initiated_by` — user/system; `user_action_id?` — доказательство explicit Retry; `status` — pending/delivered/uncertain/failed; `confirmation_level` — target_ack/certified_transport/transport_only/none; `compatibility_rule_id?`, `compatibility_rule_version?` — правило, действовавшее в момент решения; `started_at`, `completed_at?`; `final_error_code?` | N:1 к session/transcript/target; 1:N method attempts |
| `DeliveryAttempt` | Один конкретный Windows insertion method и его evidence | `id`; `delivery_operation_id` — FK; `ordinal`; `method` — unicode/send_input/clipboard; `status`; `evidence_class` — target_ack/certified_transport/transport_only/none; `expected_input_units?`, `accepted_input_units?`; `foreground_before`, `foreground_after`; `target_revalidated`; `keyboard_state_safe?`; `clipboard_set?`, `clipboard_restored?`; `started_at`, `completed_at?`; `error_code?` | N:1 к delivery operation; уникален по `(operation_id, ordinal)` и `(operation_id, method)`; evidence не содержит target text |

Recovery не является отдельной копией текста. UI строит recovery из `DictationSession.outcome`, связанных `AudioArtifact`, `TranscriptVersion`, `DeliveryOperation` и `SessionEvent`, чтобы не возникало двух расходящихся источников истины.

## Aggregate Notetaker

Все сущности этого раздела имеют статус 🔜 **M2 после personal alpha**. Они описываются заранее, но не входят в M1 schema/production code.

| Сущность | Назначение | Основные поля и причина | Связи |
|---|---|---|---|
| `NotetakerJob` | Корень resumable lifecycle готовой записи | `id`; `status` — queued/running/paused/needs_source/completed/incomplete/failed; `stage` — preflight/downloading/decoding/transcribing/stitching/committing/cleanup; `state_version`; `pause_reason?`; `last_error_code?`; `source_id`; `retain_pcm`; `created_at`, `started_at?`, `completed_at?`, `updated_at` | 1:1 source; 1:N artifacts/chunks/transcripts/events; не связан с target/insertion |
| `NotetakerSource` | Immutable snapshot принятого пользовательского источника | `id`; `job_id`; `kind` — local_file/yandex_public_file; `display_name`; `local_path?`; `normalized_public_url?` — только до durable PCM; `observed_byte_size`; `observed_mtime?`; `content_hash`; `selected_audio_stream_index`; `probe_manifest`; `url_purge_at?`; `created_at` | 1:1 job; URL/direct download metadata не переносятся в transcript |
| `NotetakerMediaArtifact` | Managed downloaded container либо PCM artifact с two-storage commit | `id`; `job_id`; `kind` — downloaded_container/pcm_chunk/retained_pcm; `commit_id`; `chunk_index?`; `staging_storage_key?`; `storage_key?`; `format`; `start_ms?`, `end_ms?`; `reserved_byte_size`; `byte_size?`; `content_hash?`; `artifact_state`; `created_at`, `deleted_at?` | N:1 job; PCM chunk 1:1 с logical chunk; внешний local source сюда не копируется |
| `NotetakerChunk` | Durable единица decode/ASR/checkpoint | `id`; `job_id`; `chunk_index`; `start_ms`; `end_ms`; `input_hash`; `decode_state`; `asr_state`; `checkpoint_version`; `committed_at?` | N:1 job; 1:1 PCM artifact; 1:N ASR attempts; уникален по `(job_id, chunk_index)` |
| `NotetakerAsrAttempt` | Воспроизводимая попытка распознавания одного chunk | `id`; `job_id`; `chunk_id`; `runtime_profile_id`; `attempt_no`; `idempotency_key`; `engine_config_hash`; `protocol_version`; `status`; lease/heartbeat timestamps; `error_code?`; allowlisted metrics | N:1 job/chunk/runtime; 1:0..1 набора raw segments |
| `NotetakerJobEvent` | Append-only история state/stage/checkpoint и crash recovery | `id`; `job_id`; `sequence_no`; `event_type`; `from_status?`, `to_status?`; `from_stage?`, `to_stage?`; `source`; `reason_code?`; allowlisted `metadata`; `occurred_at` | N:1 job; уникален по `(job_id, sequence_no)` |

## Транскрипт Notetaker

| Сущность | Назначение | Основные поля и причина | Связи |
|---|---|---|---|
| `NotetakerTranscriptVersion` | Immutable document version | `id`; `job_id`; `kind` — raw/stitched/edited/diarized/summary; `version_no`; `source_version_id?`; `generator_type`; `generator_version`; `config_hash`; `is_complete`; `content_hash`; `created_at` | N:1 job; self-reference для derived version; v1 создаёт только raw/stitched |
| `NotetakerSegment` | Упорядоченный текстовый интервал версии | `id`; `transcript_version_id`; `ordinal`; `start_ms`; `end_ms`; `text`; `source_chunk_id?`; `source_segment_id?` | N:1 transcript; уникален по `(version_id, ordinal)`; raw timing не изменяется |

Экспорт TXT/SRT/VTT — явная производная операция во внешний выбранный путь, а не managed-доменная копия. Диаризация, editing и summary зарезервированы как отдельные derived kinds, но не реализуются в v1.

## Конфигурация и персонализация

| Сущность | Назначение | Основные поля и причина | Связи |
|---|---|---|---|
| `AppConfiguration` | Versioned snapshot действующих настроек | `id` — identity snapshot; `schema_version`; `config_version` — строгий порядок; `is_active` — единственный выбранный snapshot; `hotkey_binding`; `microphone_device_id?`; `active_runtime_profile_id?` — FK; `active_cleanup_profile_id?` — FK; `startup_enabled`; `warmup_enabled`; `diagnostic_mode`; `created_at`, `activated_at?`, `superseded_at?` | N:1 optional runtime/cleanup profiles; предыдущий snapshot остаётся last-known-good |
| `CleanupProfile` | Immutable version policy для deterministic/локального cleanup | `id`; `profile_key`; `name`; `profile_version`; `method`; `settings` и `settings_hash` — валидируемая method schema; `enabled`; `created_at`, `superseded_at?` | 1:N cleanup attempts; 1:N app profiles; optional active config |
| `AppProfile` | Будущая app-scoped policy без чтения содержимого окна | `id`; `display_name`; `process_identity`; `cleanup_profile_id?` — FK; `enabled`; `created_at`, `updated_at` | N:1 optional cleanup profile; 1:N glossary entries |
| `GlossaryEntry` | Версионированная deterministic подстановка пользователя | `id`; `entry_key`; `entry_version`; `glossary_revision`; `spoken_form`; `preferred_form`; `aliases`; `scope_kind` — global/app/mode; `app_profile_id?` — FK для app scope; `mode?` — enum для mode scope; `case_policy`; `priority`; `enabled`; `created_at`, `superseded_at?` | N:0..1 app profile; cleanup attempt фиксирует использованную glossary revision |

`AppProfile` и `GlossaryEntry` спроектированы для public target, но не блокируют [personal MVP](../../idea/04-mvp/scope.md).

M2 добавляет в versioned configuration `notetaker_notice_version?`, `notetaker_notice_accepted_at?` и `yandex_import_enabled=false` по умолчанию. Изменение capability создаёт новый config snapshot; оно не запускает сеть само по себе.

## Диагностика и обслуживание

| Сущность | Назначение | Основные поля и причина | Связи |
|---|---|---|---|
| `DiagnosticEvent` | Content-free измерение стадий и отказов | `id`; `session_id?` — optional FK для session event; `component`; `event_type`; `duration_ms?`; `error_code?`; `metadata` — allowlist; `occurred_at` | N:0..1 session; не владеет пользовательским artifact |
| `MaintenanceRun` | Дедупликация и продолжение retention/orphan/delete sweep | `id`; `run_type`; `cutoff_at`; `cursor?` — content-free JSON с session/action id и normalized managed storage keys для resumable delete; `status`; `started_at`, `completed_at?`; `error_code?` | Независимая technical entity; переживает session cascade и не содержит text/audio |

Diagnostic bundle — производный экспорт с manifest/preview, а не долговечная доменная сущность. Его можно пересобрать из allowlisted events; пользовательский текст или аудио прикладываются только отдельным явным действием.

## Что сознательно не является сущностью MVP

- `User`, `Account`, `Organization`, `Role`, `Subscription` — нет аккаунта или server control plane.
- `CloudRequest` — основной продукт запрещает cloud ASR/cleanup.
- `AgentMemory` — нет автономного агента и memory consolidation.
- `RecoveryCopy` — recovery строится из единственного session aggregate, а не дублирует его.
- `TargetContent` — WiGigaDict не читает текст активного приложения.

Нерушимые ограничения схемы: [правила-нерушимые.md](правила-нерушимые.md).
