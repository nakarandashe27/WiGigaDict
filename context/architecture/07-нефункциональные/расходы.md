# Расходы WiGigaDict

## Экономический контракт архитектуры

Personal MVP не требует подписки, облачного ASR, backend или платного API. После установки приложения и модели одна дополнительная диктовка не создаёт внешний счёт: compute, storage и inference выполняются на компьютере владельца.

`0 ₽` ниже означает отсутствие обязательного внешнего платежа для уже имеющегося компьютера/интернета. Это не означает нулевое электричество, амортизацию оборудования, время разработки, поддержку или юридические расходы.

## Personal MVP — обязательные ресурсы

| Ресурс | Цена | Объём в месяц | Итого |
|---|---:|---:|---:|
| Cloud runtime/backend/database | 0 ₽ | 0 запросов | 0 ₽ |
| ASR/LLM API | 0 ₽ | 0 токенов / 0 минут | 0 ₽ |
| Локальный CPU/GPU | Уже имеющееся устройство | Зависит от audio hours и RTF | 0 ₽ внешнего счёта; электричество по формуле ниже |
| Локальный диск | Уже имеющийся SSD | ~1.93 GiB найденных model caches + ≤256 MiB pending PCM + DB/logs | 0 ₽ marginal при достаточном месте |
| Интернет | Имеющийся тариф | Первичная/явная загрузка моделей и обновлений | 0 ₽ marginal при безлимитном тарифе |
| Tauri/Rust/React/SQLite toolchain | Open-source, без runtime fee | 1 локальная установка | 0 ₽; license/SBOM obligations сохраняются |
| whisper.cpp / GigaAM / ONNX Runtime | Текущие upstream заявляют open-source лицензии | 1 выбранный engine в MVP | 0 ₽ license fee только после package-specific audit |
| CI personal alpha | Локальная Windows-сборка | По release candidate | 0 ₽ внешнего сервиса |
| Hosting/telemetry/email/payments | Не используются | 0 | 0 ₽ |
| Code signing personal alpha | Не используется; manual verified install | 0 | 0 ₽, но Windows reputation warnings приняты как alpha limitation |

Локальная инвентаризация нашла GigaAM weights `448,928,167` bytes и Whisper GGUF `1,624,555,275` bytes: вместе `2,073,483,442` bytes ≈ `1.93 GiB`. Это planning reference, не размер production package: оба artifact ещё должны пройти compatibility/license gate.

## M2 Notetaker — локальные ресурсы

Notetaker не создаёт ASR/API subscription cost, но увеличивает локальный disk/compute budget:

| Ресурс | Hard cap / формула | Внешний счёт |
|---|---:|---:|
| Local/Yandex source | ≤2 GiB, ≤4 часа | 0 ₽; Yandex использует пользовательский интернет только по команде |
| PCM S16LE 16 kHz mono | `32 000 bytes/s`; 4 часа = `460 800 000 bytes` ≈ `439.5 MiB` | 0 ₽; временное локальное место |
| Reservation local import | PCM worst case + 20% | ≈ `527.4 MiB` для 4 часов, плюс DB/log overhead |
| Reservation Yandex import | container cap + PCM worst case + 20% | До ≈ `2.53 GiB` на accepted 2 GiB/4h job |
| Очередь | 1 active + 2 waiting | Каждый accepted job обязан иметь собственную reservation; aggregate worst case измеряется soak, не обещается как «почти 2 GiB» |
| Bundled FFmpeg | Exact binary/DLL/source/license bundle | Размер фиксируется только после LGPL build spike |
| Retained PCM | Только explicit opt-in | Учитывается постоянно в storage UI до явного удаления |

После durable полного transcript временные PCM/chunks и downloaded container удаляются; transcript хранится до явного удаления. Local source не копируется. Эти правила предотвращают скрытый рост, но 4-hour + two-queued low-disk soak остаётся обязательным до повышения caps.

## Нагрузка для контрольного сценария

Плановый сценарий для сравнения, а не прогноз поведения пользователя: 1 000 диктовок по 30 секунд в месяц.

- Audio input: `30 000 секунд = 8.33 часа`.
- PCM S16LE mono 16 kHz: `32 000 bytes/second`, то есть около `960 MB = 0.894 GiB` последовательной записи за месяц до safe-point deletion.
- Hard session cap 32 MiB соответствует примерно `1 048.6 секунды = 17 мин 29 с` непрерывного PCM.
- Hard pending cap 256 MiB соответствует примерно `2 ч 20 мин` незавершённого аудио; очередь не может расти дальше.

Электричество считается после benchmark:

`E_ASR_kWh = audio_hours × RTF × incremental_ASR_watts / 1000`

`monthly_energy_cost = (E_ASR_kWh + E_optional_warmup_kWh) × local_tariff_per_kWh`

До измерения RTF и мощности сумма остаётся неизвестной; подставлять TDP CPU/GPU вместо измеренной wall/telemetry delta запрещено. Warm-up выключен по умолчанию, поэтому его стоимость равна нулю без отдельного opt-in.

## Распределение локальных моделей

| Задача | Модель/runtime | Макс токенов или входа | Оптимизация |
|---|---|---|---|
| ASR personal MVP | Один победитель benchmark: Whisper или GigaAM | Tokens N/A; ≤32 MiB PCM/session, один ASR lease | Один resident profile, optional warm-up, CPU safety profile, bounded FIFO |
| Второй ASR adapter | Не входит в blocker MVP | Не получает runtime budget | Package не скачивается и worker не грузится, пока функция не включена после MVP |
| Meaning-preserving cleanup | Deterministic Rust rules | Tokens N/A; transcript payload ≤1 MiB UTF-8 | Versioned rules/glossary; нет LLM и model load |
| Prompt optimization | Будущая явная команда | Не применяется в MVP | Budget выбирается отдельным исследованием; только локальная модель/явная команда, без скрытого вызова |
| Cloud fallback | Запрещён | 0 | Отсутствует в code path и offline gate |
| Notetaker v1 | Тот же active RuntimeProfile | ≤4 часа media; 1 active + 2 waiting | Dictation preempts; no second resident model; window/VAD выбираются benchmark |

Здесь неприменима стратегия «дешёвая LLM для 80% запросов»: runtime не маршрутизирует текст между платными моделями. Экономия достигается выбором одного локального ASR profile, отсутствием cloud calls и benchmark-driven CPU/GPU policy.

## Стоимость распространения публичного продукта

Локальная архитектура сохраняет `0 ₽` server inference cost и при 100 пользователях. Появляются разовые/операционные расходы распространения:

| Ресурс | Цена | Объём | Итого/формула |
|---|---:|---:|---:|
| Installer/app updates | Тариф выбранного российского mirror/CDN | `N_downloads × app_package_bytes` | `storage + egress + requests + VAT` |
| Model distribution | Тот же или отдельный artifact store | `N_model_downloads × selected_model_bytes` | Доминирующий network cost; веса не вшиваются в installer |
| Code-signing certificate/service | Коммерческое предложение на дату запуска | 1 active identity | `annual_cost / 12` для monthly planning |
| CI/release runner | Тариф выбранного CI либо собственный Windows runner | builds × minutes + artifact retention | По фактическому pipeline |
| Domain/status/support | Тарифы на дату запуска | 1 домен + support load | Не относится к inference, но входит в product OPEX |
| Billing/ККТ/чеки | Выбирается в business/legal phase | transactions | Provider fee + fiscalization + VAT/tax treatment |

Если 100 новых пользователей один раз скачивают оба найденных planning artifacts, передаётся около `193 GiB`; production должен скачивать только выбранную пользователем модель, поэтому реальный объём обязан быть ниже и считается из signed package manifest. Цены CDN, certificate и платежей не фиксируются сейчас: провайдер не выбран, а значения меняются. За 30 дней до public beta требуется сравнение минимум двух доступных в РФ вариантов с НДС, egress, request, storage, SLA и способом оплаты.

## Cost guardrails

- Базовая диктовка никогда не зависит от платного endpoint, аккаунта или active subscription.
- Нельзя скрыто включить cloud fallback ради качества/скорости.
- Model weights не входят в app installer: пользователь загружает только выбранный package или импортирует его offline.
- Одновременно resident только активный ASR profile; второй engine не прогревается фоном.
- Warm-up, autostart и update checks — отдельные opt-in.
- Dictation audio удаляется после durable raw safe point; delivered Dictation text — через 15 дней, если не pinned. Notetaker temporary media удаляется после full/incomplete transcript commit, а transcript — только явно.
- Yandex ingress не превращает local ASR в сетевую услугу: URL/download bytes появляются только по явной команде, recurring API cost и backend отсутствуют.
- Pending queue, logs, bundles и downloads имеют hard disk limits; disk growth не становится способом «купить надёжность».
- Новый сетевой сервис обязан указать стоимость на 100/1 000/10 000 MAU, data residency, exit cost и offline degradation до архитектурного approval.
- Release не принимается, если mandatory recurring external spend personal MVP становится больше 0 ₽.

## Измерения, обязательные по roadmap

Неизвестные расходы превращаются в задачи, а не в выдуманные числа:

1. Benchmark Whisper/GigaAM фиксирует RTF, incremental CPU/GPU watts, RAM/VRAM, cold/warm load и energy на один audio hour.
2. Release build фиксирует installer, sidecar, runtime и каждый model package в bytes.
3. Storage soak на 1 000 диктовок проверяет write volume, steady-state DB/WAL/logs и retention после restart.
4. Public launch estimate отдельно считает artifact distribution, signing, CI, support и billing по актуальным предложениям.
5. License/SBOM audit подтверждает, что runtime, weights и notices допускают выбранный способ бесплатного/коммерческого распространения.
6. Notetaker soak фиксирует disk reservation high-water mark для 4-hour job + two waiting, FFmpeg package bytes, decode/ASR energy и cleanup steady state.
