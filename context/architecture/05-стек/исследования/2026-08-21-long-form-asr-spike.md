# Research spike: model-independent long-form ASR

- Дата проверки: 2026-08-21
- Статус: **завершено 2 сентября 2026: benchmark и четырёхчасовой soak пройдены, профиль принят**
- Область: M0 research evidence для будущего M2 Notetaker; production implementation запрещена до M1 gates

## Проверенные upstream constraints

- Официальный GigaAM short path `.transcribe` рассчитан на audio до 25 секунд. Официальный long-form path использует `pyannote.audio` и Hugging Face token, поэтому не подходит Rust-only/offline production boundary WiGigaDict: [GigaAM usage](https://github.com/salute-developers/GigaAM#usage).
- whisper.cpp C API отдаёт segment timestamps; его parallel/chunked path прямо предупреждает о возможной деградации на chunk boundaries: [whisper.h](https://github.com/ggml-org/whisper.cpp/blob/master/include/whisper.h).
- Upstream stream/VAD examples экспонируют window/step/keep/threshold/padding как параметры, а не универсальные константы: [stream.cpp](https://github.com/ggml-org/whisper.cpp/blob/master/examples/stream/stream.cpp), [VAD example](https://github.com/ggml-org/whisper.cpp/blob/master/examples/vad-speech-segments/README.md).

## Канонический контракт sidecar

Вход — immutable managed PCM artifact/chunk reference с `artifact_id`, content hash, `sample_rate_hz=16000`, `channels=1`, `duration_ms`, media interval и `RuntimeProfile` fingerprint. Sidecar не принимает произвольный пользовательский path или URL.

Выход — versioned набор сегментов:

```text
Segment {
  ordinal
  start_ms
  end_ms
  text
  source_chunk_id
}
```

`start_ms/end_ms` — целые миллисекунды исходной media timeline, интервал `[start_ms, end_ms)`. Сегменты монотонны. Engine-specific confidence/word timing допустимы только как optional enrichment. Raw chunk output immutable; stitching создаёт отдельную version и сохраняет `window_ms`, `overlap_ms`, `vad_mode`, seam policy/version и provenance.

## Гипотезы benchmark

- Большее window снижает edge loss до определённого предела, но увеличивает latency/RAM.
- Недостаточный overlap обрезает boundary words; избыточный создаёт duplicate seams и лишний compute.
- VAD полезен на silence-heavy media, но агрессивные threshold/padding дают edge loss/drift.
- Internal и external VAD сравниваются как разные profiles.
- Победитель выбирается по Pareto-набору `truncation + duplicate seams + timestamp drift + WER/CER + RTF + RSS/VRAM`, а не только по WER.

Конкретные window/overlap/VAD не фиксируются архитектурой до evidence.

## Gates

### Fixtures 30/60 секунд

- речевые маркеры расположены до/после каждой планируемой seam boundary;
- ни одной потерянной или продублированной marker phrase;
- монотонные `[start_ms,end_ms)`, финальный контрольный marker с ошибкой ≤1 секунды;
- zero silent leading/trailing truncation;
- 60-second fixture включает минимум две seams и crash/restart после одного committed chunk;
- output повторяем при том же engine/model/config/protocol fingerprint.

### Soak до 4 часов

- zero lost/duplicate committed chunks и незамеченных обрывов;
- no cumulative drift regression; каждый контрольный marker остаётся в принятом допуске;
- bounded RSS/VRAM/temp disk без восходящего leak trend;
- несколько crash/restart cycles продолжают последний checkpoint без duplicate artifacts;
- повторные Dictation preempt/resume освобождают runtime на chunk boundary без повреждения job;
- round-trip canonical segments → TXT/SRT/VTT не меняет intervals/order/text.

## Результаты (2 сентября 2026)

Harness: `scripts/long-form-benchmark.ps1` (research-only, production-модуль Notetaker не создавался). Фикстура собирается конкатенацией синтезированных SAPI фраз, поэтому точное время каждого маркера известно по построению: эталонный декодер и ручная разметка не нужны. Маркер — «маркер» плюс три существительных из словаря двадцати слов, что даёт 8000 уникальных фраз и отличает потерю от дубля.

### Принятый профиль

Окно **30 с**, перекрытие **2 с**, шаг 28 с; движок whisper `large-v3-turbo-q5`, профиль vulkan; язык фиксирован. Внешний VAD не понадобился: чанки нарезаются по времени, а тишину модель размечает сама.

**Seam policy v2:** чанк отдаёт только сегменты, начавшиеся в его собственном шаге `[start, start + step)`; перекрытие существует ради контекста движка, а не ради выдачи. Дополнительно на пересечении времени снимается дубль по повтору слов. Обе части выведены из наблюдений, а не из общих соображений, и обе закрыты регрессиями в self-test:

- политика «перекрытие принадлежит раннему чанку» теряет речь: последняя фраза раннего чанка обрезана краем окна, и вместе с ней уходит весь хвост, который должен был отдать следующий чанк;
- отбора по началу сегмента мало: сегмент раннего чанка может пересечь границу владения, а следующий чанк начинает свой первый сегмент ровно с неё и повторяет ту же речь. На четырёхчасовом прогоне это дало 13 дублей из 1552 маркеров.

**Отказ движка — штатная ситуация.** На монотонном звуке декодер уходит в цикл и выдаёт сегмент за пределами чанка. Валидация воркера (`end_ms > duration_ms`) отвергает такой результат целиком, и это правильно: инвариант `end_ms ≤ duration_ms` нарушать нельзя. На первом четырёхчасовом прогоне так отклонилось **24 чанка из 515 (4,7%)**, и все 24 приняты со второй попытки. Повтор идёт укороченным окном `step + 0,5 с`: тот же вход дал бы тот же результат, а урезанный хвост меняет контекст декодера, при этом окно по-прежнему накрывает всю зону ответственности чанка. Разнообразие исходного звука тоже влияет: пять фраз-наполнителей по кругу провоцировали зацикливание, двадцать четыре с паузами разной длины — заметно реже.

Сверено с боевым трактом диктовки по коду: там та же ситуация уже закрыта и менять нечего. Воркер отвергает невалидные сегменты и выходит с ненулевым кодом, sidecar классифицирует это как `worker_exited` (`EngineError::transient() == true`), а диспетчер ставит ровно один повтор — `MAX_LEASE_GENERATIONS = 2`, — и по [ADR-008](../../06-решения/журнал-решений/2026-08-27-008-cpu-retry-и-прозрачные-исходы.md) повтор уходит с Vulkan на CPU, то есть с изменённым входом, как и в harness. Вторая проверка тех же правил живёт в `EngineOutput::validate` на стороне sidecar; она даёт `invalid_worker_output`, который **не** считается transient, но при нынешнем воркере этот путь недостижим: он валидирует первым.

### Fixtures 30 и 60 секунд

30 с: 4 маркера, 2 чанка, все гейты зелёные. 60 с: 7 маркеров, 3 чанка, **два шва**, падение после первого зафиксированного чанка и продолжение с checkpoint без пересчёта и дублей. Повторный прогон по той же фикстуре с тем же fingerprint дал **побайтово идентичный транскрипт**.

### Soak на 4 часах

14 403 с медиа, 1552 маркера, 515 чанков, inference 587 с, **RTF 0,0408**, пик рабочего множества **627 МБ** без роста между половинами прогона (каждый чанк — отдельный процесс воркера). Десять вытеснений диктовкой, все на границах чанков, работа продолжалась после каждого.

| Гейт | Итог |
|---|---|
| Промахи не концентрируются на швах | на швах 3,9% из 180, вне швов 5,2% из 1372 |
| Маркеры не продублированы | 0 |
| Интервалы монотонны и полуоткрыты | 3155 сегментов |
| Дрейф финального маркера ≤1 с | финальный 0 мс, максимальный 554 мс |
| Обрезки в начале и в конце нет | первый и последний маркер на месте |
| Чанки зафиксированы без потерь и дублей | 515 из 515, незавершённых 0 |
| Отказы движка восстановлены повтором | 24 отклонения, 0 невосстановленных |
| Память ограничена, тренда роста нет | пик 627 МБ |
| Экспорт TXT/SRT/VTT не меняет текст и порядок | 3155 строк txt, 3155 блоков srt |

**Циклы падения:** два настоящих убийства процесса посреди чанка (после 15 и 31 зафиксированного) плюс имитация на 60-секундной фикстуре. После каждого — ноль незавершённых `.part`, продолжение ровно с последнего зафиксированного чанка, ноль дублей, финальный прогон 43 из 43 с зелёными гейтами. Чанк объявляется зафиксированным только после атомарного переименования готового файла, поэтому убийство посреди записи не оставляет полуфабрикат.

### Чем меряется дрейф и почему не строгим совпадением

Whisper включает в сегмент предшествующую тишину, поэтому «начало сегмента минус плановое время маркера» меряет манеру нарезки, а не дрейф: на 30-секундной фикстуре это давало ложные 1,3 с. Принятая метрика — попадает ли плановое время маркера внутрь несущего сегмента; ошибка равна расстоянию наружу.

Точное совпадение всех трёх слов маркера дало 82,9%, не меньше двух из трёх — 95,0%. **Это качество распознавания, а не целостность конвейера, и гейтом не является:** три редких существительных подряд — тяжёлый случай, а речь синтетическая. Гейтом служит сравнение промахов на швах и вне швов: ошибка нарезки дала бы всплеск именно на швах, а наблюдается обратное — 3,9% против 5,2%. Настоящие цифры качества на живой речи остаются за Step 16 и ADR-006.

## Вывод

Contract design пригоден для обоих engine families. Benchmark и four-hour soak **пройдены 2 сентября 2026** на профиле whisper turbo/vulkan, окно 30 с, перекрытие 2 с; официальный Python/pyannote/HF-token GigaAM long-form по-прежнему не становится production fallback. Notetaker production code остаётся запрещён до M1 gates: закрытым считается research-этап R2, а не сама функция.
