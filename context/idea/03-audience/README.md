# Целевая аудитория

## Первичный пользователь

Первичный пользователь — Windows-разработчик или технический специалист, который ежедневно работает с Codex, Claude Code, Cursor, VS Code и другими AI-инструментами, часто формулирует длинные задачи на русском языке с английской технической лексикой и хочет диктовать их быстрее, не покидая текущую рабочую среду. Для него важны надёжность вставки, точность терминов, локальная обработка рабочего контекста и отсутствие обязательной подписки.

## Порядок расширения

1. **Разработчики и технические специалисты на Windows** — первый внешний сегмент после personal-first версии.
2. **Другие Windows knowledge workers** — менеджеры, аналитики, авторы, специалисты поддержки и все, кто регулярно создаёт длинные тексты.
3. **Российские организации** — пользователи и команды, которым критичны локальная обработка, конфиденциальность, контролируемое развёртывание и возможность использовать GigaAM.
4. **Пользователи с требованиями доступности** — важное возможное направление, но оно не заявляется как поддерживаемый сегмент без отдельного исследования, тестирования и соответствующего качества UX.

## Осознанное ограничение

MVP не пытается одинаково хорошо обслужить все сегменты. Продуктовые решения сначала оптимизируются под ежедневный рабочий поток технического пользователя, который ставит задачи AI-агентам.
