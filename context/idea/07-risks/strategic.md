# Стратегические риски

## R-09 — Коммерческий рынок размывает personal-first MVP

**Уровень:** medium

**Что пошло не так.** Проект начал строить аккаунты, billing, команды, enterprise policies, облачные сценарии и macOS до стабилизации личного Windows workflow.

**Почему.** Будущая возможность российского рынка выглядит крупнее узкой личной задачи и незаметно меняет критерий приоритета. Для одного разработчика каждый новый контур умножает поддержку, безопасность и упаковку, не улучшая golden flow.

**Что сделать сейчас.** Заморозить коммерческий scope до прохождения трёх blocker gates и принимать функцию только при доказанном улучшении completed-dictation loop. Возможность роста сохранять через adapter/policy boundaries, но не через преждевременную инфраструктуру.

**Ранний сигнал:** количество roadmap items вне `hold → speak → release → paste/recover` до прохождения MVP gates.

Основание: [порядок расширения аудитории](../03-audience/README.md#порядок-расширения), [компания из одного человека](../06-principles/one-person-company.md).
