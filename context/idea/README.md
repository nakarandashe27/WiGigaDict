# Контекст идеи

## One-pager

Проект — локальное Windows-приложение для быстрого голосового ввода в любое активное текстовое поле. Главная сцена — постановка подробных задач AI-агентам в IDE: пользователь нажимает глобальную клавишу, говорит, нажимает её ещё раз и получает очищенный, но не искажённый текст прямо у курсора.

Personal-first MVP не требует подписки и обязательного облака, использует один лучший по локальному бенчмарку движок Whisper/GigaAM и сохраняет архитектурную возможность подключить второй. Надёжность — главный приоритет: ни одна завершённая диктовка не должна быть безвозвратно потеряна.

Wispr Flow задаёт эталон поведения и качества UX, но бренд, тексты и визуальные активы создаются самостоятельно. После доказательства личного сценария продукт может расшириться сначала на Windows-разработчиков, затем на широких knowledge workers и российские организации с требованиями локальной обработки.
