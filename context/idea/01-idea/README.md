# Идея

## Супер-идея

Локальное Windows-приложение для быстрого голосового ввода в любое активное текстовое поле, которое использует Whisper и GigaAM, особенно хорошо работает с IDE и AI-агентами и не требует подписки или отправки аудио в облако.

## Контекст

Первичная задача — личный инструмент для ускорения постановки задач в VS Code, Codex, Claude Code и других средах разработки. Пользователь нажимает глобальную горячую клавишу, диктует мысль естественной речью, а приложение локально преобразует запись в аккуратный текст и вставляет его в текущее поле ввода. IDE и чаты с AI-агентами — главная «золотая сцена», но механизм не должен быть искусственно ограничен только ими.

Продукт начинается как бесплатное personal-first решение для Windows и использует уже доступные локальные модели Whisper и GigaAM. Базовый принцип — аудио и расшифровка не покидают устройство без явного решения пользователя. Это устраняет подписку, снижает зависимость от внешних сервисов и создаёт основу для сценариев, где конфиденциальность рабочего текста критична.

Архитектура должна оставлять путь к коммерческому Windows-first продукту для российского рынка, ориентированному на локальную обработку и отечественную модель GigaAM; поддержка macOS рассматривается как последующее расширение. Wispr Flow задаёт эталон пользовательского опыта, а готовые open-source решения должны быть исследованы до начала собственной реализации, чтобы использовать существующие компоненты или fork, если это дешевле и быстрее.

## Подтверждённая граница

- Сейчас: персональный инструмент, Windows-first, universal text insertion.
- Главный сценарий: голосовая постановка задач AI-агентам и работа в IDE.
- Затем: возможность вырасти в коммерческий российский продукт.
- Позже: macOS и более широкая продуктовая линейка.
