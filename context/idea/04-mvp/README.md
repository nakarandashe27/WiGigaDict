# MVP

## Цель

Доказать на одном надёжном Windows-сценарии, что локальная голосовая постановка задач AI-агентам действительно быстрее ручного набора и даёт текст, пригодный к использованию после минимальной проверки.

## Главная проверка

[Золотая сцена MVP](one-killer-feature.md): длинная техническая диктовка в поле Codex превращается в чистый, локально обработанный и восстановимый текст у курсора.
