# Критерии успеха для пользователя

## Приоритеты

Качество продукта оценивается в порядке: **надёжность → точность → скорость → экономность ресурсов**.

## 1. Надёжность — жёсткое требование

- Ни одна завершённая диктовка не должна бесследно теряться.
- Если вставка в активное поле невозможна, распознанный текст должен оставаться доступным для восстановления.
- Пользователь всегда понимает текущее состояние: запись, обработка, успешная вставка или ошибка.
- Сбой модели, потеря фокуса или недоступное поле ввода не должны приводить к молчаливой потере результата.

## 2. Точность

- Русская техническая речь распознаётся с минимальным числом ручных исправлений.
- Английские термины, названия моделей, библиотек, команд и продуктов корректно сохраняются внутри русской речи настолько, насколько позволяет выбранная модель и словарь.
- Пунктуация и базовая структура текста делают результат пригодным для отправки AI-агенту после быстрой проверки.
- Численный порог качества будет установлен после сравнительного тестирования Whisper и GigaAM на реальных пользовательских диктовках.

## 3. Скорость

- После отпускания клавиши пользователь получает текст достаточно быстро, чтобы голосовой ввод ощущался продолжением печати, а не отдельной задачей транскрибации.
- Целевые значения задержки для коротких, средних и длинных фрагментов будут определены по локальным замерам.
- Ради существенного повышения точности допустима дополнительная задержка, пока она не разрушает рабочий поток.

## 4. Экономность ресурсов

- Фоновое приложение не должно заметно ухудшать отзывчивость IDE и инструментов разработки.
- Транскрибация не должна бесконтрольно занимать CPU, GPU или RAM, особенно когда параллельно работают локальные AI-модели.
- Допустимые лимиты будут определены после инвентаризации компьютера и нагрузочного тестирования.

## Поведенческий признак успеха

Пользователь добровольно выбирает голосовой ввод для регулярной постановки задач AI-агентам и возвращается к клавиатуре преимущественно для точечных правок, кода и коротких команд.

## Метрики, требующие бенчмарка

- Доля диктовок без потери результата.
- Частота ошибок автоматической вставки.
- Объём ручных исправлений на реальном наборе технических фраз.
- Задержка от отпускания клавиши до готового текста.
- Пиковая и фоновая нагрузка на CPU, GPU и RAM.
