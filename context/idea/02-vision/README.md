# Видение продукта

## Кратко

Приложение превращает диктовку в естественное продолжение набора текста: пользователь нажимает глобальную клавишу, говорит, нажимает её ещё раз и получает локально распознанный текст непосредственно в активном поле. Главная рабочая сцена — постановка подробных задач AI-агентам в IDE и чатах.

## Приоритет продукта

Надёжность важнее точности, точность важнее минимальной задержки, а производительность контролируется локальными бенчмарками и не должна мешать основной работе пользователя.
